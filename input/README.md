# Вхідні файли

Покладіть сюди щонайменше два файли `*.xlsx`.

Один файл — один логічний масив для порівняння. Усі аркуші одного файла
трактуються як окремі описи, але об'єднуються у підсумках і графіках.

На кожному аркуші скрипт очікує таблицю з номером справи, заголовком, крайніми
датами, кількістю аркушів і примітками. Перед таблицею можна вказати метадані
`Архів`, `Фонд`, `Опис` та `Мова` у першому стовпці, а їх значення — у другому.

Робочі книги не входять до репозиторію: правило `.gitignore` не дозволяє
випадково додати файли `input/*.xlsx` до коміту.
