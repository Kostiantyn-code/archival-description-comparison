# Тематичні словники

Проєкт містить словники 11 тематичних категорій українською та російською
мовами. Перелік категорій, підписи, макроблоки й шляхи до файлів визначає
`config/categories.yaml`.

| Поле | Призначення |
|---|---|
| `id`, `macroblock` | Ідентифікатор категорії та її макроблок |
| `minimum_score` | Мінімальна сума балів для присвоєння теми |
| `strong_phrases` | Сильні фразові ознаки, 4 бали |
| `strong_terms` | Сильні терміни, 3 бали |
| `contextual_terms` | Слабкі контекстні ознаки, 1 бал |
| `context_only_terms`, `context_only_phrases` | Контекстна мітка без предметної теми |
| `context_rules` | Правила співнаявності термінів із заданою вагою |
| `exclude_phrases` | Фрази, що маскуються перед перевіркою категорії |
| `review_terms` | Ознаки для ручної перевірки випадків поблизу порога |

Файли `auxiliary/ambiguities.yaml` для кожної мови містять міжкатегоріальні
обмеження та правила для неоднозначних термінів.

Не видаляйте схожі словоформи автоматично: у поточній бальній моделі вони
можуть бути окремими ознаками. Зміни словників варто перевіряти на списках
класифікованих і некласифікованих справ, а також фіксувати номером версії у
`config/categories.yaml`.

Стоп-слова з `config/stopwords_uk.txt` і `config/stopwords_ru.txt`
використовуються у лексичному аналізі, але не впливають на тематичну
класифікацію.

Методичні пояснення наведено у [`docs/methodology.md`](../docs/methodology.md).
Початкові словники й правила розвиваються у проєкті
[`archival-description-analysis`](https://github.com/Kostiantyn-code/archival-description-analysis).
